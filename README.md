# Agro Dairy — Smart Dairy Farm Management System

Agro Dairy is a full-stack web application for managing a dairy farm: cow records,
daily milk production, vaccinations, feed inventory, farm finances and alerts.

## Development

You need Node.js and npm (or bun).

```sh
npm install
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Postgres (Supabase-compatible backend)
